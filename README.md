# Улица-колесо, версия 1 (3DGS)

Сайт: https://street-wheel-v1.vercel.app — деплоится автоматически при пуше в `main` (Vercel).

Самая первая версия [street-wheel](https://github.com/letmeshock-uae/street-wheel) в чистом виде:
без рассказа, сносок и интерфейса, с коротким швом — и с цитатой Стива Джобса из частиц вдоль улицы.

Длинная улица из Gaussian Splatting (`olaya_3dgs_yup.sog`) свёрнута в колесо: пользователь стоит на
асфальте на «дне» колеса, скроллит — и идёт по кругу. Впереди улица встаёт стеной и уходит над головой.
Вблизи — полная детализация, дальше всё реже, а самое дальнее парит в воздухе отдельными частицами.
Каждый сплат «рождается» частицей и слетается на место по мере приближения.

```
tools/build_ring.py     подготовка данных (Python + numpy)
web/                    вьюер (Vite + TypeScript, без зависимостей, ~40 КБ JS)
  src/ring.ts           математика изгиба и кривая «проявления» (общая для всех)
  src/shaders.ts        WebGL2-шейдер сплатов: изгиб, сборка из частиц, «лимбо»
  src/sort.worker.ts    сортировка по ИЗОГНУТЫМ позициям
  src/decode.worker.ts  загрузка и распаковка кусков
  src/streamer.ts       стриминг LOD по расстоянию вдоль улицы, вытеснение
  src/particletext.ts   цитата из частиц: раскладка по кольцу, шрифт Geist
  src/hud.ts            миникарта-колесо (без подписей)
  public/data/          сгенерированные данные
```

## Запуск

```bash
cd web && npm install && npm run dev
```

Сборка для хостинга: `npm run build` → папка `web/dist` (любой статический хостинг).
Файлы `*.bin` уже сжаты gzip и распаковываются в браузере — настраивать сжатие на сервере не нужно;
им стоит выставить долгий кэш.

## Шов

Концы улицы растворяются в частицы на последних ~8 м, а облако частиц шва заполняет ±10 м вокруг
стыка (в первой версии было ±34 м). Ширина задаётся константой `SEAM` в `web/src/main.ts`; подобрать
на лету можно через URL: `?seam=14` (метры).

## Цитата

Пять фраз стоят через равные доли кольца (L/6) в разных плоскостях: посреди улицы лицом к идущему,
слева и справа вдоль улицы (развёрнуты к идущему на 65°), над головой с наклоном и наискосок слева.
Последняя — «Everything else is secondary.» — лежит на асфальте поперёк пути ровно на шве.
Путь по умолчанию начинается в 12 м за швом, так что фразы идут по порядку.

Надписи собираются в браузере: строки рисуются шрифтом Geist (`@fontsource-variable/geist`, без
внешних запросов) на холст, каждый пиксель становится плоским сплатом, ранг точки — её порядок в
тексте. Вдали надпись — редкая пыль, по мере приближения «пишется» слева направо, строка за строкой
(`TEXT_REVEAL` в `src/shaders.ts`: полностью — ближе 22 м, начинает — с 90 м), а когда проходишь
сквозь неё, снова рассыпается в частицы. Текст и раскладка — `QUOTE`, `LAST` и вызовы `block`/`wall`
в `src/particletext.ts`.

## Счётчик кругов

В левом нижнем углу — сколько кругов пройдено: число растёт, когда человек пересекает шов вперёд
от точки старта, и уменьшается, если он вернётся назад через шов (ниже нуля не опускается).
Код — `updateLaps` в `src/main.ts`.

## Подготовка данных

Данные в `web/public/data` уже собраны. Модель на самом деле **y-down** (земля на y≈0, здания в
отрицательных y), скрипт по умолчанию поворачивает её на 180° вокруг X. Для y-up модели — флаг `--no-flip`.

```bash
npx @playcanvas/splat-transform olaya_3dgs_yup.sog -H 0 /tmp/olaya_sh0.ply
python3 tools/build_ring.py /tmp/olaya_sh0.ply web/public/data
```

Что делает скрипт: выравнивает ось улицы и уровень земли (иначе концы кольца не сойдутся),
режет коридор, выбрасывает сплаты с непрозрачностью < 2% и крупнее 6 м (12 млн → 6,1 млн),
режет улицу на сегменты по 6 м, внутри сегмента упорядочивает сплаты «по важности со случайностью»
и делит порядок на 6 тиров. Любой префикс — равномерно разрежённая версия сегмента, поэтому
LOD = сколько тиров загружено.

## Как устроено

- **Изгиб.** Камера стоит на месте, мир сворачивается вокруг неё: `θ = κ·d`, где `d` — расстояние вдоль
  улицы до пользователя. Ковариации сплатов умножаются на якобиан изгиба, поэтому сплаты не рвутся.
  Сортировка в воркере идёт по уже изогнутым позициям.
- **Проявление.** Доля видимых сплатов падает как `(densNear / d)^densPow` — стохастический
  «дизеринг» по рангу. Сплат у порога видимости появляется частицей и слетается на место; вдали всё
  сжато в точки и медленно парит.
- **Стриминг.** Загружаются только тиры, нужные сегменту на его расстоянии; впереди по ходу — в
  первую очередь. Догруженные куски прилетают роем частиц.
- **Под слабые устройства.** Профили `low/mid/high` выбираются по устройству (телефон → low), затем
  адаптивно по времени кадра: сначала снижается разрешение, потом радиус деталей.

## Параметры URL

`?tune` — панель живой настройки (значения запоминаются в браузере), `?debug` — статистика (Shift+D),
`?seam=10` — ширина шва, `?notext` — без цитаты, `?q=low|mid|high`, `?s=55` — стартовая точка, `?eye=1.7` — высота глаз,
`?lane=-8` — полоса, `?pitch=0.3`, `?fov=78`, `?exp=1.15` — экспозиция, `?nointro`.
